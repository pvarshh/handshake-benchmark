# The Cost of Saying Hello

Reproducibility package for **"The Cost of Saying Hello: An Empirical Study of
Handshake Overhead in AI Agent Communication Protocols"** (arXiv preprint,
cs.MA).

The benchmark measures the handshake/initialization phase — discovery,
capability exchange, session establishment, readiness — of three AI agent
communication protocols, head-to-head, using their official Python SDKs:

| Protocol | Variant(s) | SDK | Cold round trips |
|---|---|---|---|
| MCP (Model Context Protocol) | legacy era (spec ≤ 2025-11-25) and modern era (spec 2026-07-28) | `mcp` 2.0.0 | 3 / 2 |
| A2A (Agent2Agent) | spec v1.0.0, JSON-RPC binding | `a2a-sdk` 1.1.2 | 1 |
| ACP (Agent Communication Protocol) | spec 1.0 (frozen; merged into A2A 2025-08) | `acp-sdk` 1.0.3 | 1 |

## Layout

```
agents/     minimal counterpart agents (echo capability) + degraded variants
harness/    instrumented client runners, byte-counting/delay TCP relay, scenarios, CLI
results/    raw per-run JSONL for every cell in the paper + summary.json + meta.json
analysis/   generates every figure, table, and in-text number in the paper
paper/      LaTeX sources and built PDFs (see "The paper" below)
scenarios/  note on where the scenario/cell table lives (it is code, not config)
```

## The paper

`paper/main.tex` is the canonical full-length paper (arXiv preprint), built
with `tectonic paper/main.tex`. `paper/workshop.tex` is a 6-page anonymised
version for the AgenticOS workshop at NeurIPS 2026 (non-archival, so it does
not preclude a later archival submission); it reuses the same generated
numbers, tables, and figures, so both trace to the same data.
It uses `wsstyle.sty`, a self-contained NeurIPS-alike single-column layout
(10pt, 5.5in x 9in text block) vendored alongside it. Before submitting to a
venue with its own style file, read the header of `wsstyle.sty` first: it
defines `\keywords`, which the paper uses right after the abstract.

Everything quoted in the text is generated, never hand-typed:

| input | generated by |
| --- | --- |
| `paper/numbers.tex` | `analysis/numbers.py` (every in-text number) |
| `paper/tables/*.tex` | `analysis/tables.py` |
| `paper/figures/*.pdf` | `analysis/figures.py`, at final size so LaTeX never rescales |

`python -m analysis.run_all` rewrites all three from `results/raw`.

## One-command reproduction

```bash
# 1. Environment (Python 3.12; uv recommended)
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt

# 2. Raw data (~25 min on a laptop; writes results/raw/*.jsonl)
.venv/bin/python -m harness.run --scenario all --n 50 --network both --out results/raw
.venv/bin/python -m harness.baseline --n 50 --out results/raw/baseline.jsonl
.venv/bin/python -m harness.rtt_sweep   # RTT sweep figure data (~7 min)

# 3. All figures, tables, and numbers.tex (writes into paper/)
.venv/bin/python -m analysis.run_all

# 4. Paper PDFs
tectonic paper/main.tex        # full-length preprint
tectonic paper/workshop.tex    # 6-page anonymised workshop version
```

To see one instrumented handshake per protocol, with the observed request
sequence printed, run `python -m harness.spike_check`. It is a diagnostic,
not part of the reproduction path above.

Scenarios: `s1` cold start, `s2` warm repeat, `s3` capability mismatch,
`s4a` slow counterpart (2 s/response), `s4b` truncated metadata,
`s4c` version mismatch. Network conditions: `local` (loopback) and `rtt50`
(userspace relay adding 25 ms per direction). N=50 measured runs per cell
after 5 discarded warmups; every JSONL row is one run with the full
request/response event list.

## Version pins

Python 3.12.13 · mcp 2.0.0 · a2a-sdk 1.1.2 · acp-sdk 1.0.3 · httpx 0.28.1 ·
uvicorn 0.34.3 · fastapi 0.115.14 · starlette 0.46.2 · matplotlib 3.11.1 ·
tiktoken 0.13.0. `fastapi` is pinned below 0.116 because `acp-sdk` 1.0.3
(the final release of the archived ACP project) is incompatible with later
FastAPI validation behavior.

Measurements in the paper were taken 2026-08-10 on an Apple-silicon Mac
(Darwin 25.5.0, arm64), all processes on loopback.
